🚀 TechSales - Banco de Dados (SQL Server)

Projeto de banco de dados relacional para gestão de vendas de eletrônicos, desenvolvido em SQL Server (T-SQL) com foco em normalização e integridade de dados.

📌 Estrutura do Banco

O projeto conta com 4 tabelas principais:

tabela_clientes: Dados de cadastro dos clientes e status de conta.

produtos: Catálogo de produtos com estoque e preços.

tabela_vendas: Registro das vendas vinculadas aos clientes.

tabela_item_vendas: Itens e quantidades pertencentes a cada venda.

📂 Arquivos do Projeto

CRIAÇÃO DE BANCO DE DADOS.sql: Script DDL com a criação de tabelas, chaves primárias/estrangeiras e validações (CHECK).

INSERINDO OS DADOS TechSales.sql: Script DML com a massa de dados para testes.

VERIFICANDO OS DADOS - TechSales.sql: Script para validação dos registros inseridos.

🛠️ Tecnologias:

- Microsoft SQL Server
- T-SQL
